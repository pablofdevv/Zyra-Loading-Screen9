# 🚀 Zyra Loading Screen 9 - Hyperspace Portal Edition

Welcome to **Zyra-Loading-Screen-9**, an immersive Cyberpunk loading screen resource by **Zyra Store**. Features a 3D warp speed particle hyperspace tunnel background effect for FiveM roleplay servers.

## 🛠️ Key Features

- **Hyperspace Particle Tunnel:** Interactive 3D canvas animation simulating a warp-speed space tunnel transition.
- **Cyberpunk Futuristic Aesthetics:** Neon glow highlights, sleek dark overlays, and interactive NUI elements.
- **Live Audio Controller:** Playlist music player with volume bar, mute control, and track info.
- **Server News & Rules Drawer:** Interactive cards displaying community updates, server rules, and social media links.

---

## 📦 Installation Instructions

1. **Copy the Resource:**
   Copy `Zyra-Loading-Screen-9` to your server's `resources` directory:
   `resources/[zyra]/Zyra-Loading-Screen-9`

2. **Update `server.cfg`:**
   Add this line to `server.cfg`:
   ```cfg
   ensure Zyra-Loading-Screen-9
   ```

3. **Restart Server:**
   Save `server.cfg` and restart FiveM server or run:
   ```cmd
   refresh
   ensure Zyra-Loading-Screen-9
   ```
